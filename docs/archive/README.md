# Documentation Archive

Read-only home for **closed** round audits, closed diagnoses, and superseded
investigations. Files here are moved byte-for-byte and never edited in place — append
corrections to the living ledger in the active workstream folder instead.

## Subfolders

| Subfolder | Contents |
|---|---|
| [`ws2-video-ingest/`](ws2-video-ingest/) | Closed video-ingest diagnoses (Bug 3, Step 10 Windows fetch) |

WS3 export archive subfolder (`ws3-export/`) will be populated in Phase 2 after CC's
hardening branch lands.

## Retention

Git history is the ultimate backstop. The archive exists so references resolve without a
full checkout. Docs with zero inbound refs across two consecutive workstream close-outs
may move to git-history-only in a dedicated cleanup pass — not automatic.
