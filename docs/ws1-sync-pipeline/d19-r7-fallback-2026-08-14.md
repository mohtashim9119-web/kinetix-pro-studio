## Step 2 — R.7 fallback rule (defined before coding)

A word whose FA confidence falls below `CONF_MIN` (0.3) keeps its
FA-produced `start_sec`/`end_sec` exactly as measured — never dropped,
never overwritten with a Whisper timestamp — and gains a new boolean
`needsReview` flag (`true` when `confidence < CONF_MIN`), reusing the
codebase's existing `HeadingOverlay.needsReview` naming convention
(`src/types.ts`) rather than inventing a new one.

Weighing the three options named in the task brief:

- **Drop the word's timing** — rejected. It would punch a hole in the
  `wordIndex`-keyed array D18 just made gapless and index-contiguous; a
  consumer joining on `wordIndex` shouldn't have to handle missing entries,
  and a low-confidence timestamp is still real signal (e.g. for
  visualizing where alignment struggled), not noise worth discarding.
- **Fall back to the Whisper time for that word** — rejected at this layer
  specifically. `fa_align`'s Rust entrypoint (`fa.rs`) receives
  `audio_path`, `chunks: Vec<FaChunkInput>` (`start_sec`/`end_sec`/`text`
  only), and `language` — no per-word Whisper timing crosses this IPC
  boundary at all. A real fallback would require a new IPC parameter,
  which both the "no IPC wiring" constraint and the current architecture
  rule out. That merge belongs on the TS side, where FA and Whisper results
  are already both in scope together — not inside the Rust FA path this
  slice is scoped to.
- **Keep it flagged** — the only option buildable at this layer without
  scope creep, and the most conservative: nothing is invented, nothing is
  silently discarded, and the trust decision moves to whoever reads
  `faWordTimings`. A consumer that ignores `needsReview` still gets the
  real (if occasionally noisy) FA-measured time rather than a gap or a
  fabricated one; a careful consumer can filter or highlight on the flag
  exactly as existing `HeadingOverlay` readers already do.

**Recommended and implemented: keep it flagged.**

## Step 3 — implementation

- `FaWordSpan` gained `pub needs_review: bool`.

  `syncConstants.ts`'s value without touching that file.

tests in `fa.rs`, all using verbatim (confidence, word) pairs read from

(`.work-phase4/replay/173/tokens_fa.json` — matched — and
`tokens_mismatch-shuffled.json` — mismatched; both local, gitignored, same

- `needs_review_fires_on_real_mismatched_sub_threshold_words` — 20 real
